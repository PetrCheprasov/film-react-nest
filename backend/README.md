# Backend — афиша кинотеатра

NestJS API для списка фильмов, расписания сеансов и бронирования мест. Префикс маршрутов: `/api/afisha`.

## Требования

- Node.js 18+
- MongoDB (локально или в Docker)

## Установка

```bash
cd backend
npm ci
```

Скопируйте файл окружения и при необходимости измените значения:

```bash
cp .env.example .env
```

## Переменные окружения

| Переменная        | Описание                                      | Пример по умолчанию                    |
|-------------------|-----------------------------------------------|----------------------------------------|
| `DATABASE_DRIVER` | Драйвер БД (сейчас используется `mongodb`)    | `mongodb`                              |
| `DATABASE_URL`    | Строка подключения к MongoDB                  | `mongodb://127.0.0.1:27017/practicum`  |
| `PORT`            | Порт HTTP-сервера                             | `3000`                                 |
| `DEBUG`           | Уровень логов debug (опционально)             | —                                      |

## Подготовка MongoDB

1. Установите и запустите MongoDB.
2. Загрузите тестовые данные скриптом из корня репозитория:

```bash
mongosh < test/mongodb_initial_stub.js
```

Если используется устаревшая консоль `mongo`, выполните тот же файл через неё (из каталога `backend`).

Убедитесь, что имя базы в `DATABASE_URL` совпадает с базой, в которую загружены фильмы (в примере — `prac` или `practicum` в зависимости от вашего `.env`).

## Запуск

```bash
# разработка с перезагрузкой
npm run start:dev

# отладка
npm run start:debug

# production-сборка и запуск
npm run build
npm run start:prod
```

После старта API доступен по адресу `http://localhost:<PORT>/api/afisha`.

## Основные эндпоинты

| Метод | Путь                    | Описание              |
|-------|-------------------------|-----------------------|
| GET   | `/films`                | Список фильмов        |
| GET   | `/films/:id/schedule`   | Расписание сеансов    |
| POST  | `/order`                | Бронирование билетов  |

Статические файлы (постеры) отдаются по `/content/afisha`.

## Проверка

Пример запроса списка фильмов:

```bash
curl http://localhost:3000/api/afisha/films
```
